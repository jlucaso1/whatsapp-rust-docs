## Performance

**History sync: store compressed payload, expose streaming reader ([#853](https://github.com/oxidezap/whatsapp-rust/pull/853))**

Previously, `Event::HistorySync` carried the fully decompressed blob. A typical `InitialBootstrap` chunk is 5–20 MB inflated — roughly 10× the compressed size. If you registered a history sync handler, your bot paid O(decompressed) retained memory for every queued event.

The event is now `Box<LazyHistorySync>`, which retains the original zlib-compressed bytes (~10× smaller) and decodes on demand.

**New API surface on `LazyHistorySync`:**

```rust
// Metadata — no decompression needed
lazy.sync_type()       // i32
lazy.chunk_order()     // Option<u32>
lazy.progress()        // Option<u32>
lazy.peer_data_request_session_id() // Option<&str>
lazy.decompressed_size()            // usize
lazy.compressed_bytes()             // &Bytes (zero-copy)

// Old: full decode (now cached via OnceLock)
if let Some(h) = lazy.get() { /* &wa::HistorySync */ }

// New: streaming (memory-bounded, prefer for large blobs)
let mut stream = lazy.stream();
while let Some(conv) = stream.next_conversation()? {
    process(conv);
}
let rest = stream.remainder()?;
```
