description: "SignalStores is no longer generic over its store types. The encrypt fan-out now uses type-erased dyn fields, removing ~16 KiB from the .text section. Two new blanket-impl'd traits — CloneableSessionStore and CloneableIdentityStore — replace the Clone bounds."

## Breaking Change

**`wacore::send::SignalStores` is now non-generic ([#861](https://github.com/oxidezap/whatsapp-rust/pull/861))**

`SignalStores` previously carried four type parameters that propagated through every function in the encrypt tree:

```rust
// Before
pub struct SignalStores<'a, S, I, P, SP> { ... }

pub async fn encrypt_for_devices<'a, S, I, P, SP>(
    stores: &mut SignalStores<'a, S, I, P, SP>,
    ...
) -> Result<EncryptResult>
where
    S: SessionStore + Clone + Send + Sync + 'static,
    I: IdentityKeyStore + Clone + Send + Sync + 'static,
    P: PreKeyStore + Send + Sync,
    SP: SignedPreKeyStore + Send + Sync,
```

The struct and all functions that take it (`encrypt_for_devices`, `ensure_sessions_for_devices`, `encrypt_for_devices_with_sessions`, `prepare_dm_stanza`, `prepare_group_stanza`) are now non-generic:

```rust
// After
pub struct SignalStores<'_> { ... }

pub async fn encrypt_for_devices(
    stores: &mut SignalStores<'_>,
    ...
) -> Result<EncryptResult>
```

The store fields are now `dyn` trait objects, so the entire encrypt + session-establishment tree compiles to a single instantiation instead of one copy per concrete adapter set.

## Migration

**Concrete adapters need no code changes.** The two `Clone` bounds on session and identity stores are now expressed via two new object-safe traits:

- `wacore::send::encrypt::CloneableSessionStore` — blanket-impl'd for every `T: SessionStore + Clone + Send + Sync + 'static`
- `wacore::send::encrypt::CloneableIdentityStore` — blanket-impl'd for every `T: IdentityKeyStore + Clone + Send + Sync + 'static`

If you construct `SignalStores` directly (e.g. in a custom `wacore` integration), update any explicit type annotation:

```rust
// Before
let stores: SignalStores<'_, SessionAdapter, IdentityAdapter, PreKeyAdapter, SignedPreKeyAdapter> = ...;

// After
let stores: SignalStores<'_> = ...;
```

The field assignment is identical — just remove the type parameters. The `.clone()` calls in the fan-out become `.clone_box()` internally; callers are unaffected.

## Performance

Removed **~16 KiB** from the `.text` section (fat-LTO release build, stripped binary −13.6 KiB). In production, where a single concrete adapter set is in use, most of the duplicate instantiations were already folded by the linker, so the reduction is modest but real and zero-risk.

| Metric | Before | After | Delta |
|--------|--------|-------|-------|
| `.text` | 11,856,758 B | 11,840,246 B | **−16,512 B** |
| Stripped binary | 13,996,056 B | 13,982,136 B | **−13,920 B** |
